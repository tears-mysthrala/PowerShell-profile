## Evidence and decisions

- Apache 2.4.68 → 2.4.69 failed at Fossies with HTTP 401. Apache Lounge's exact
  archive was downloaded over HTTPS and matched its published SHA256:
  `ca272e0b75abad78b1e4029a0753b20ff2232d2d857e8eebeea5d469c5776977`.
  Scoop verified the hash and installed it. `httpd -v` reported 2.4.69 and
  `httpd -t` returned `Syntax OK`. The new Scoop version migrated metadata to
  `scoop-install.json`; recovery now handles both layouts and restores the main
  bucket after success or failure. `scoop status` subsequently reported everything OK.
- `uv tool upgrade --all` failed before updating remaining tools because
  compliance-watcher referenced a deleted local 0.1.0 wheel. The existing local
  0.2.0 release wheel matched its release manifest SHA256:
  `45006fba58b96b2b1e755426013d89fb3546dce995da27240736e06270972ee4`.
  It was copied into `%LOCALAPPDATA%/SystemUpgrade/artifacts` and installed with
  `uv tool install --force --python 3.13`. Its receipt points to the stable copy;
  `cw --help` passed. `uv tool update-shell` added the missing executable path.
  The modified `Update-Uv` successfully checked all five installed tools.
- The old npm code deleted arbitrary dot directories and suppressed deletion
  failures while announcing success. It now archives only recognized old staging
  directories with active-process checks and reports native command failures.
  Live `Update-Npm` verified the cache, updated npm and globals, and returned an
  empty outdated-package JSON object without a command error.
- Absent Ruby and Conda now produce informational skips. Incomplete Ruby remains
  an error. The updater uses fresh command discovery and records both detailed
  output from repaired branches and a full transcript for each actual alias run.
